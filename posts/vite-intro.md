## Vite 的核心思路

Vite 在开发模式下不做打包，直接利用浏览器原生的 ES Module 支持按需加载模块，所以冷启动几乎是瞬时的。

## 与传统打包器的区别

| 对比项 | Webpack 等传统方案 | Vite |
| --- | --- | --- |
| 开发启动 | 先整体打包 | 按需编译，秒级启动 |
| 热更新 | 重新构建相关模块图 | 只更新单个模块 |

## 生产构建

生产环境下 Vite 使用 Rollup 打包，兼顾了开发速度和产物优化：

```bash
npm run build
```
